Review workflow
Context and consumption limits

File and module reviews use loaded Changes diffs without a GitHub token. Only optional GitHub API context uses this token. For private repositories, API context needs Pull requests: read and Contents: read for the source repository, including forks. If API access fails, the review uses loaded changes instead. The token stays in trusted local extension storage; it is not sent to an AI provider.
